# Ball item sprites

25 original raster sprites from the PokeAPI/sprites repository, downloaded for offline use. Each selectable Catalog.Balls ID (1–26 excluding Cherish/16) has its own verified PNG. See manifest.json for source URLs, dimensions and SHA-256 hashes. These are existing game item sprites, not generated substitutes. Pokémon artwork remains the property of its respective owners; see the upstream repository and project third-party notices.
